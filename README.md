# Observe Mod Menu

An in-game **Mod Menu Manager** for *Observe*, built with **BepInEx 6.0 (IL2CPP)**.  
This mod provides a clean, custom UI directly integrated into the game's main menu, allowing players to manage and inspect installed mods effortlessly.

---

## ✨ Features

- 🎨 **Seamless UI Integration**: Designed to perfectly match the original game's main menu style.
- 🔌 **Mod Management**: Enable or disable installed BepInEx plugins directly within the game.
- 📋 **Mod Inspector**: Displays detailed information for each mod, including:
  - Mod Name
  - Version
  - GUID
  - Current Status (ON / OFF)
- ⌨️ **Hotkey Support**: Toggle the menu anytime by pressing the `Insert` key.

---

## 🛠️ Prerequisites

Before installing this mod, make sure you have:
- **Observe** (Steam version)
- **BepInEx 6.0 Bleeding Edge (IL2CPP)** installed in your game directory.

---
